# Selld

**The online store built for Filipino social sellers — no commission, ever.**

Working name: **Selld** (`selld.ph` / `selld.store`) — same truncation pattern as Servd.
Alternates under consideration: Cartd, Shipd, Kartd, Tindahan.io

---

## What this repo is

This repo currently holds the **positioning and offer strategy** for Selld: who we're
selling to, what we're selling, at what price, and with what proof. Everything here is
meant to be the single source of truth that ads, landing pages, sales calls, and the
product roadmap all trace back to.

Product code will land alongside these docs. When it does, the rule is: **if a feature
doesn't serve the avatar in [`docs/avatar.md`](docs/avatar.md), it doesn't ship.**

## The one thing to remember

We don't compete on features. We compete on:

> **Gawa ito para sa'yo, at hindi ka kinakaltasan.**

Hyper-local operational reality plus a flat fee. That's the wedge — same as Servd.
